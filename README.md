# Medi-X — Patient Health Portal

Medi-X is a React + Vite patient portal prototype for exploring a healthcare dashboard experience. It includes dashboard summaries, appointments, medications, doctor profiles, reports, settings, support, theme switching, and appointment-booking interactions.

## Tech stack

- React and React DOM
- Vite
- React Router
- Framer Motion
- Lucide React icons

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Notes

This repository is a UI prototype. Authentication, patient records, and appointment data are not backed by a production healthcare service. Do not use it to store real patient information or as a clinical system without appropriate security, privacy, data-integrity, and regulatory review.
